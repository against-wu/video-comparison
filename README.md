# Research project page

Academic project page template with side-by-side video comparisons.

Content and animated illustrations are placeholders.

To edit, append `?edit=1` to the published page URL. Changes are stored only in your browser until you export the website ZIP and commit the updated files to this repository.

Video comparisons support 2-4 methods, group playback, shared seeking and 1x/2x/4x/8x speeds. Local videos are included in the exported ZIP.

Deploy from branch `main`, folder `/ (root)` in Settings > Pages.
