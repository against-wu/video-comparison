填写同一评测设置下的结果。分数使用 0–100 百分制；留空表示未填写。汇总分请填入评测结果，不会自动计算。

编辑视频对比

支持 MP4 / WebM 链接或本地视频。本地文件只在浏览器中预览和保存，导出 ZIP 时会一并打包；不会自动上传。建议使用 H.264 编码的 MP4。

导出 GitHub Pages 网页

将下载一个 ZIP，包含页面与已添加的本地视频。解压后，把其中全部文件上传到 GitHub 仓库即可。

1. 解压 ZIP，将 index.html 和 media 文件夹放在仓库根目录。
2. 在仓库 Settings → Pages 中选择从分支发布：main / root。
3. 等待 GitHub 完成发布，访问生成的网页地址。

导出页默认隐藏编辑按钮；在网址后加 ?edit=1 可继续编辑。编辑不自动更新线上页面，需要重新导出并上传。
